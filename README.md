## ✨ Features

| Feature | Description |
|---|---|
| 🎙️ **Speech to Text** | Upload or record audio and get instant transcription |
| 🌍 **Any Language** | Supports transcription in any spoken language |
| ⚡ **Real-Time Results** | Fast AI-powered transcription via backend API |
| 🎨 **Modern UI** | Clean and responsive React interface |

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, JavaScript |
| Build Tool | Vite |
| Deployment | Vercel |
| API | Connected to Spring Boot backend on Render |

---

## 💬 How to Use

1. Open the **[Live Demo](https://ai-audio-transcribe-frontend-7en5tjb74-itsaryanjain1.vercel.app)**
2. Upload an audio file or record your voice
3. Select your language (or let AI auto-detect it)
4. Hit **Transcribe** and get your text instantly!
